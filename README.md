# Trening skrzydłowego

Aplikacja treningowa dla młodego skrzydłowego i taty. Strona jest w folderze `web/`
i publikuje się sama na GitHub Pages po każdej zmianie w gałęzi `main`.

Dane rodziny są w Google Firestore (`families/<kod rodziny>/docs`), nie w tym repozytorium.
Telefony łączą się 12-znakowym kodem rodziny z Ustawień aplikacji.
